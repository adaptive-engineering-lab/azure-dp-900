This is the DP-900 (Microsoft Azure Data Fundamentals) study app, forked from
an AZ-900 app, which was itself forked from a DP-700 app. For product scope,
data model and conventions, read `DP900-Game-Spec.md`; for setup, commands
and architecture, read `README.md`. Exam taxonomy (domains, topics, learning
paths) lives in `exams.config.json`. Remaining launch work is tracked in
`DP900-LAUNCH-TASKS.md`.

The feature specs under `specs/` are DP-700-era build history: useful for how
a feature was built, but their exam content (Fabric, code review, exam pacing)
does not apply. `DP900-Game-Spec.md` wins where they disagree.
